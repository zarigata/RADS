## 🎯 Scope

### 1. env Module 🌍 HIGH PRIORITY

**Purpose:** Environment variable access - essential for configuration and system integration.

**API Design:**
```rads
import env;

// Get environment variable
turbo home = env.get("HOME");
turbo path = env.get("PATH");

// Set environment variable
env.set("MY_VAR", "value");

// Check if exists
if (env.has("HOME")) {
    echo("HOME is set");
}

// List all environment variables
turbo all = env.list();
echo("PATH = " + all["PATH"]);

// Get all paths from PATH variable
turbo paths = env.paths();
for (int i = 0; i < length(paths); i = i + 1) {
    echo(paths[i]);
}
```

**Functions:**
| Function | Description |
|----------|-------------|
| `env.get(name)` | Get environment variable value |
| `env.set(name, value)` | Set environment variable |
| `env.has(name)` | Check if variable exists |
| `env.list()` | Get all variables as struct |
| `env.paths()` | Parse PATH into array |

**Implementation:**
- File: `src/stdlib/stdlib_env.c`, `src/stdlib/stdlib_env.h`
- Uses: C standard library `<stdlib.h>` `getenv()`, `setenv()`
- No external dependencies

### 2. CLI Module 🖥️ HIGH PRIORITY

**Purpose:** Command-line argument parsing - essential for building CLI tools.

**API Design:**
```rads
import cli;

// Simple argument access
turbo args = cli.args();  // Raw arguments array

// Parse with spec
turbo config = cli.parse({
    name: { type: "string", required: true },
    count: { type: "int", default: 1 },
    verbose: { type: "bool", alias: "v" },
    output: { type: "string", alias: "o" }
});

echo("Name: " + config.name);
echo("Count: " + config.count);
echo("Verbose: " + config.verbose);
echo("Output: " + config.output);

// Check for flags
if (cli.has_flag("--help") || cli.has_flag("-h")) {
    echo("Usage: myapp --name <name> [--count N] [-v] [-o file]");
}

// Get flag value
turbo file = cli.flag("--file");
turbo file_short = cli.flag("-f");
```

**Functions:**
| Function | Description |
|----------|-------------|
| `cli.args()` | Get raw argument array |
| `cli.parse(spec)` | Parse with specification |
| `cli.has_flag(name)` | Check if flag present |
| `cli.flag(name)` | Get flag value |
| `cli.flags()` | Get all flags |

**Implementation:**
- File: `src/stdlib/stdlib_cli.c`, `src/stdlib/stdlib_cli.h`
- Uses: Command-line arguments from main()
- No external dependencies

### 3. CSV Module 📊 MEDIUM PRIORITY

**Purpose:** CSV file handling - common data interchange format.

**API Design:**
```rads
import csv;

// Parse CSV string
turbo data = csv.parse("name,age,city\nAlice,30,NYC\nBob,25,LA");
// Returns array of structs: [{name: "Alice", age: "30", city: "NYC"}, ...]

// Parse with options
turbo data2 = csv.parse(content, { delimiter: ";", header: true });

// Convert to CSV
turbo people = [
    { name: "Alice", age: 30 },
    { name: "Bob", age: 25 }
];
turbo csv_str = csv.stringify(people);
// "name,age\nAlice,30\nBob,25"

// Read CSV file
turbo rows = csv.read("data.csv");

// Write CSV file
csv.write("output.csv", people, { delimiter: "," });
```

**Functions:**
| Function | Description |
|----------|-------------|
| `csv.parse(str)` | Parse CSV string |
| `csv.parse(str, opts)` | Parse with options |
| `csv.stringify(data)` | Convert to CSV string |
| `csv.stringify(data, opts)` | Convert with options |
| `csv.read(path)` | Read CSV file |
| `csv.write(path, data)` | Write CSV file |

**Options:**
- `delimiter` - Field separator (default: `,`)
- `header` - First row is header (default: `true`)
- `quote` - Quote character (default: `"`)
- `escape` - Escape character (default: `\`)

**Implementation:**
- File: `src/stdlib/stdlib_csv.c`, `src/stdlib/stdlib_csv.h`
- Uses: C standard library
- No external dependencies

### 4. base64 Module 🔐 MEDIUM PRIORITY

**Purpose:** Base64 encoding/decoding - essential for data encoding.

**API Design:**
```rads
import base64;

// Encode string
turbo encoded = base64.encode("Hello, World!");
echo(encoded);  // "SGVsbG8sIFdvcmxkIQ=="

// Decode string
turbo decoded = base64.decode("SGVsbG8sIFdvcmxkIQ==");
echo(decoded);  // "Hello, World!"

// Encode binary data (as array)
turbo data = [72, 101, 108, 108, 111];
turbo enc = base64.encode_bytes(data);

// Decode to bytes
turbo bytes = base64.decode_bytes(enc);
```

**Functions:**
| Function | Description |
|----------|-------------|
| `base64.encode(str)` | Encode string to base64 |
| `base64.decode(str)` | Decode base64 to string |
| `base64.encode_bytes(arr)` | Encode byte array |
| `base64.decode_bytes(str)` | Decode to byte array |

**Implementation:**
- File: `src/stdlib/stdlib_base64.c`, `src/stdlib/stdlib_base64.h`
- Uses: Custom implementation (no OpenSSL needed)
- No external dependencies
